Curvify is designed to make creating curved platforms and curved PSDs/APGs.

Curvify is currently in **redevelopment**. It is undergoing a massive overhaul, aiming to more dependent on the MTR mod itself.

Please report any problems in the discord server: https://discord.gg/H2Ma3UEVgp
Gladly accepting anyone who will be willing to help code and tweak.

### Planned Features
* Undo and Redo history
* Ghost previews before placement
* Rail-aware snapping and automatic alignment
* Curved platform generation
* Curved Platform Screen Door (PSD) support
