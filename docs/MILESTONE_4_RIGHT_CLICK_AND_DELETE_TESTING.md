# Milestone 4 — Right-click and Delete update

## Right-click placement workflow
1. Hold the Builder Wand and right-click an empty location.
2. A pending PSD preview appears at that exact location.
3. Move it with the arrow/Page Up/Page Down keys or rotate it with `[` and `]`.
4. Right-click again anywhere to confirm the PSD **at its current preview transform**.
5. No new preview is created automatically.
6. Right-click another empty location to start the next pending PSD. It inherits the last placed PSD's pack, rotation, and scale.

## Existing PSD workflow
1. Right-click an existing PSD.
2. Its properties panel opens.
3. Press **Delete PSD** to permanently remove it.
4. Confirm the door disappears, the selection clears, and it remains deleted after reloading the world.

## Pending properties
The pending PSD properties panel deliberately has no Delete PSD button because the object has not been saved to the world yet.
