# Milestone 3.4 testing — exact TJMetro BMT model

1. Install MTR 4.0.5, Tianjin Metro 1.1.1, Fabric API, and the new MetroBuilder JAR.
2. Enter a Creative world and place a PSD with the Builder Wand.
3. Confirm the lower two blocks are made from four original TJMetro door quarters.
4. Confirm each quarter has the original 2/16-block depth and the original atlas UV mapping.
5. Confirm the total assembly remains exactly 2 blocks wide and 3 blocks tall.
6. View the door from the front, back, both sides, above, and below.
7. Place doors at several unsnapped yaw values and confirm the model rotates as one object.
8. Save and reopen the world and confirm positions and rotations are unchanged.

The neutral white BMT header casing is rendered in Beta 1. Dynamic route maps and station-name text require platform data and are reserved for later integration.
